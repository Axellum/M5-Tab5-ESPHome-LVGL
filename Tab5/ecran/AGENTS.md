# AGENTS.md — `Tab5/ecran/` (the LVGL layer)

Read with the root [`AGENTS.md`](../../AGENTS.md) and [`Tab5/AGENTS.md`](../AGENTS.md). Claude Code loads this file (through the `CLAUDE.md` next to it) only once it reads or edits a file of this folder.

`ecran/` is the LVGL layer (`tab5_custom.h`, one header per module `tab5_<module>.h` since 2026-10-08). The pure helpers it uses are in [`Tab5/socle/AGENTS.md`](../socle/AGENTS.md).

## Toolbox — LVGL layer (`Tab5/ecran/`, `Tab5/paquets/`)

Before writing a helper, look here and `grep` the name; when you add a shared helper of this layer, add its line here. Naming and style of new code: « Conventions du nouveau code » in [`Tab5/README.md`](../README.md).

Instant transitions, no fade (the author's taste, root `AGENTS.md`): the only animation kept on purpose is the centre card rotation (short slide + fade, kept by the author on 2026-09-29 after the "text only" trial).

- **LVGL writes that compare first** (no repaint for an unchanged value): `ui_text()`, `ui_text_color()`, `ui_style_num()` / `ui_style_couleur()` (any local style property of the main part), `ui_hidden()`, `ui_x()` / `ui_y()`, `ui_police()` — `Tab5/ecran/tab5_internal.h`. LVGL 9.5.0 already compares in `lv_obj_add_flag()` / `lv_obj_remove_flag()` and `lv_obj_set_x/y/width/height()`, never in `lv_label_set_text()` or `lv_obj_set_style_*()`.
- **A tap or long press at the end of a swipe** (it must open nothing): `ui_appui_glisse()` — `Tab5/ecran/tab5_internal.h`.
- **The natural width of a text in a label's font** (before cutting it, or to size a button to its name): `ui_largeur_texte(lbl, txt)` — `Tab5/ecran/tab5_internal.h`.
- **An event to Home Assistant only once it listens** (no field): `ha_evenement_envoyer("esphome.…")` in a `wait_until` lambda — `Tab5/ecran/tab5_journal.h` (sent only to « Home Assistant » clients subscribed to actions; false, nothing sent, until one is; `tools/contrat_api.py` and `tests/test_actions_ha.py` read these calls as emissions).
- **A refused payload**: `payload_refuse()`, `payload_trop_long()` (one `ESP_LOGW` under the module's `tab5.<module>` tag: the reason and the size, never the content) — `Tab5/ecran/tab5_internal.h`.
- **Text from Home Assistant**: `texte_ha_copier()` (valid UTF-8, only the glyphs the fonts have, cut on a character boundary), `texte_ha_coupe()` (one line, « … » past a width), `ha_alerte_texte()` (coded alert text), `normalize_text_utf8()`, `set_label_text_utf8()` — `Tab5/ecran/tab5_internal.h`.
- **Elements of a room on the five places** (up to twenty, [ADR-0066](../../docs/decisions/0066-rooms-count-cut-tiles.md)): `disposition::disposer(presents, positions_fixes)` (whole / halves / quarters, each element's place and cell; the weather keeps element T on place T up to five), `disposition::case_rect()` and the count of whole tiles, halves and quarters `compter(n)` (same namespace) — `Tab5/socle/tab5_disposition.h`; a room's layout `disposition_piece(r, meteo)` and the whole element of a place `element_de_place()` — `Tab5/ecran/tab5_tuiles.cpp`; the cells of a cut place `cases_peindre_place()`, `case_peindre()`, `case_ancre()` — `Tab5/ecran/tab5_tuiles_cases.cpp`. The T character of a key « tRT » / « crRT » / « ceRT » (0-9 then a-j): `tuile_car()`, read back by `tuile_index()` — `Tab5/socle/tab5_modele_ha.h`. Rows of a popup with one row per element, five per page: `PopupPieces` / `pieces_calculer()` (`tab5_tuiles_popups.cpp`) and the House pages (`tab5_maison.cpp`).
- **What a tile does when touched**: one row per type in `kGestes` (`GesteType`: acts, command, wheel, window), `gestes(d, clim_connue)` (options r / o / k / t / e / m applied), `ouvrir_fenetre()` (the window of a long press: lights, shutter, device, remote, air conditioner, energy) and `clim_cible()` (the blueprint's air conditioner with option m, else the tile's) — `Tab5/ecran/tab5_tuiles.cpp`. A new tile type = one row there, not a new `switch`.
- **A popup showing one tile** (light, shutter, device): derive its state from `PopupTuile<&TuilesUI::x_popup>` (room, tile, `ouvert()`, `montre(r, t)`, `en_grille()`), open it with `popup_tuile_ouvrir()` and re-check it on new definitions with `popup_tuile_revalider()` — `Tab5/ecran/tab5_tuiles_popups.cpp`. A popup listing one kind of tile, one page per room (Lights, Shutters): `PopupPieces<&TuilesUI::x_popup>` + `pieces_calculer(p, garde, r, t)`, rows `piece_ligne.yaml` painted by `tuile_peindre_ligne()` — same file (ADR-0046).
- **A popup with pages** (left / right swipe, page names at the top, nothing with fewer than two pages) — the only one, `Tab5/ecran/tab5_pages.cpp`, declared in `tab5_internal.h` (ADR-0046; Settings, Lights, Shutters, Temperature, Weather, Alarm clock). The popup keeps its page; the brick keeps nothing. Give a long-lived (static) `PagesPopup` {popup, `nombre()`, `courante()`, `afficher(i)`} to `pages_brancher()` once the popup exists (calling it again is harmless): the swipe stops at the popup, wraps, ignores a swipe started on a slider, an arc or a roller, and mutes the finger's release. Page names: `pages_onglets(onglets, max, noms, n, courante)` on `pages_onglet.yaml` buttons (right-aligned against the ×, 200 px at most, `pages_onglet_largeur(n)`, names cut with « … »), or your own placement plus `choix_peindre()` for the active one (Temperature does: its tabs start after its title; Settings, Weather and Alarm clock keep fixed, translated names: `reglages_onglet.yaml` with `prefixe:`, which calls `${prefixe}_afficher_page(page)`, and an optional width `w`). Never a second `LV_EVENT_GESTURE` handler (`tests/test_pages_popup.py`; the climate carousel, ADR-0038, is the last one left).
- **Every climate the tablet knows** (the blueprint's, then each `cli` tile without option m whose settings came, then each room's own climate, [ADR-0040](../../docs/decisions/0040-room-climate.md); one entry per unit): `clims_enumerer()` and `ClimRef` — `Tab5/ecran/tab5_internal.h`, defined in `tab5_clim.cpp` ([ADR-0038](../../docs/decisions/0038-climate-carousel.md)). The pages of the climate popup's carousel, its opening and its dots read only this list; another kind of climate = one line there and one case in `clim_ref_afficher()`.
- **Repainting most of the screen in one go** (theme switch, [#501](https://github.com/Axellum/M5-Tab5-ESPHome-LVGL/pull/501)): `theme_bascule_debut()` / `theme_bascule_fin()` — `Tab5/ecran/tab5_theme.h` (the whole screen invalidated once, then invalidation off and the label subscriptions drained until the end; never across a `wait_until` or a `delay`). The drain alone, counted, shared by the boot and the switch: `lvgl_vidage_abonnes(true / false)` — `Tab5/socle/tab5_demarrage.h`.
- **Popups and screens**: `animate_popup_open()` / `animate_popup_close()` (`Tab5/ecran/tab5_anim.h`), `popup_voile_carte(popup, carte)` for a popup whose scrim is not opaque (Musique, 70 %; the calendar's day, 60 % over the calendar): LVGL then draws its opaque card without redrawing what it hides (`tab5_anim.h`, call it before each opening; not for an opaque scrim, where it was measured to cost more than it saves), `close_popup_if_open()` (`Tab5/ecran/tab5_internal.h`), the script `tab5_ecran_ouvrir` (`Tab5/paquets/tab5-navigation.yaml`, the only way to open a screen), one `ModalRegistry::add(...)` line in `tab5_modal_registry_init` (`Tab5/paquets/tab5-navigation.yaml`, ADR-0013; its opening script as 4th argument when it has one; a registered POPUP or LAYER that is hidden sits 10 000 px below the screen, `translate_y`, put back before its first frame — GARAGE in `Tab5/ecran/tab5_registry.h`: never read its absolute coordinates while it is hidden), the chrome `modal_scrim.yaml` + `modal_header.yaml` and the tokens `${modal_card_w}` / `${modal_card_h}` / `${modal_body_y}` (`Tab5/paquets/tab5-ui-tokens.yaml`, ADR-0009).
- **Page dots and the action wheel**: `pagination_afficher()`, `tuile_roue_ouvrir()` / `roue_ouvrir()` (any anchor; `RoueTete::mots` writes a word beside each button), `clim_roue_ouvrir()` (the wheel of any climate, `ClimRef`, ADR-0048) — `Tab5/ecran/tab5_internal.h`. The navigation wheel of the central card: `roue_navigation_ouvrir()` (`Tab5/ecran/tab5_roue_navigation.cpp`, ADR-0042; a screen more = one line of its tables).
- **Going to a room or to a tile's popup without a tile**: `tuiles_aller_piece(r)` (HA mode on room r), `tuiles_ecran_disponible()` / `tuiles_ecran_ouvrir()` (`Ecran::LUMIERES` / `Ecran::VOLET`: the room shown first) — `Tab5/ecran/tab5_tuiles.h`.
- **Plots drawn with plain objects** (no `lv_chart`, disabled): `ui_rectangle()`, `ui_ligne()` (the points stay owned by the caller: a static array), `ui_poser()`, a monotone smoothed curve (Fritsch-Carlson, no overshoot) `ui_courbe_lisse()` — `Tab5/ecran/tab5_internal.h`. The coming hours already received: `previsions_heures_lisibles()` (how many slots of `cal_heures_data` can be drawn), a rain amount's colour `couleur_pluie_mm()` — `Tab5/ecran/tab5_internal.h`, defined in `tab5_meteo.cpp`. A weather icon at any size: `update_meteo_icon(…, echelle_pct)` with its two fonts — `Tab5/ecran/tab5_forecast.h`.
- **Zones with lines** (the row under the clock, the « Ok Nabu » panel, ADR-0031 / ADR-0041): one model and one drawing per `RangeeZone` (`Tab5/ecran/tab5_internal.h`; key letter and NVS record in `tab5_tuiles.cpp`, `Defileur` in `tab5_rangee.cpp`), widgets from `ui_components/rangee_panneau.yaml` (four elements) and `ui_components/rangee_pastilles.yaml` (dots). Turns of the central card: `kTourCentralS` (`tab5_internal.h`, the only definition); scrolling auto / fixed of the three zones: `defilement_auto(Defilement::X)`.
- **Colours**: `UIColor.X` (`Tab5/socle/tab5_tokens.h`) and the role styles of `Tab5/paquets/tab5-styles.yaml` (rule 1). The hue of a lamp colour (`color_name` sent to HA → colour shown, light popup and wheel): `lampe_teinte()` — `Tab5/ecran/tab5_tuiles_roue.cpp`, the only list.
