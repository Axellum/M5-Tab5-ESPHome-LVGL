Installer depuis le navigateurInstall from the browser

Installer le firmware sur une M5Stack Tab5 depuis le navigateur. Partagé au cas où il serve à quelqu'un. Install the firmware on an M5Stack Tab5 from your browser. Shared in case it is useful to someone.

1. Ce qu'il faut1. What you need

  • Une Tab5 reliée à l'ordinateur par un câble USB-C qui transmet les données.
  • A Tab5 connected to the computer with a USB-C cable that carries data.
  • Chrome ou Edge sur ordinateur (Web Serial) ; le bouton le signale sinon.
  • Chrome or Edge on a computer (Web Serial); the button tells you otherwise.
  • Dans la liste des ports, la tablette s'appelle « USB JTAG/serial debug unit ». Si plusieurs ports portent ce nom, débranchez la tablette : celui qui disparaît est le sien.
  • In the port list, the tablet is named "USB JTAG/serial debug unit". If several ports have that name, unplug the tablet: the one that disappears is hers.
  • Home Assistant, avec les packages et le blueprint du projet (guide).
  • Home Assistant, with the project's packages and blueprint (guide).

2. Votre révision d'écran2. Your display revision

La puce d'écran est écrite sur l'autocollant au dos, au-dessus du logo Espressif. Une étiquette « ST7123 » peut porter une ST7121 : dans le doute, essayez l'une puis l'autre (détails). The display chip is printed on the sticker on the back, above the Espressif logo. A unit labelled "ST7123" may carry an ST7121: if unsure, try one then the other (details).

4. Installer4. Install

D'abord les fichiers Home Assistant (point « Fichiers Home Assistant » plus bas) : une tablette neuve n'attend son ajout à Home Assistant que 30 minutes après son démarrage. Home Assistant files first (the "Home Assistant files" item below): a new tablet only waits 30 minutes after its start to be added to Home Assistant.

Ce navigateur ne gère pas Web Serial : utilisez Chrome ou Edge sur ordinateur. This browser has no Web Serial: use Chrome or Edge on a computer. La page doit être ouverte en HTTPS. The page must be opened over HTTPS.
  • Première installation (un Tab5 neuf porte la démo de M5Stack) : « Install », puis acceptez d'effacer l'appareil.
  • First install (a new Tab5 carries M5Stack's demo): "Install", then accept to erase the device.
  • Mise à jour d'une tablette déjà installée : « Update », sans effacer : elle garde son Wi-Fi, sa clé de Home Assistant et ses réglages.
  • Updating a tablet already set up: "Update", without erasing: it keeps its Wi-Fi, its Home Assistant key and its settings.
  • Même version déjà installée : pas de bouton « Install ». Pour repartir de zéro, « Erase User Data » (en rouge, en bas) efface tout, Wi-Fi, clé et réglages compris, puis réinstalle.
  • Same version already installed: there is no "Install" button. To start from scratch, "Erase User Data" (in red, at the bottom) erases everything, Wi-Fi, key and settings included, then installs again.
  • « Failed to initialize… holding the BOOT button » : le Tab5 n'a pas de bouton BOOT. Maintenez son bouton reset environ 2 s, jusqu'à ce que la LED verte interne clignote vite : la tablette est en mode téléchargement. Relancez « Connecter et installer » ; à la fin, un appui court sur reset la redémarre.
  • "Failed to initialize… holding the BOOT button": the Tab5 has no BOOT button. Hold its reset button for about 2 s, until the internal green LED blinks fast: the tablet is in download mode. Start "Connect and install" again; at the end, a short press on reset restarts it.
  • Fermer la fenêtre redémarre la tablette une fois : c'est normal.
  • Closing the window restarts the tablet once: that is normal.

5. Ensuite5. Then

  1. Wi-Fi : juste après l'installation, le même bouton propose de le régler (Improv par l'USB). Sinon, connectez un téléphone au réseau ouvert « Tab5 Fallback AP » et choisissez votre réseau.
  2. Wi-Fi: right after installing, the same button offers to set it (Improv over USB). Otherwise, connect a phone to the open network "Tab5 Fallback AP" and pick your network.
  3. Fichiers Home Assistant, s'ils ne sont pas déjà en place (Home Assistant 2026.8 ou plus récent) : téléchargez tab5_home_assistant.zip et décompressez-le dans le dossier config/ de Home Assistant, celui de configuration.yaml ; ajoutez la ligne packages: !include_dir_named packages sous homeassistant: dans configuration.yaml ; Outils de développement → YAML → Vérifier la configuration, puis redémarrez Home Assistant. Choisissez ensuite vos sources dans les listes « Tab5 · … » (guide, étape 1). Depuis la 3.7.0, l'intégration « Tab5 » de HACS peut poser ces fichiers et les mettre à jour en un clic (avec HACS) :
    Ouvrir Tab5 dans HACS HACS doit déjà être installé : il propose d'ajouter le dépôt, puis « Download ». La ligne packages: reste à ajouter.
  4. Home Assistant files, if they are not in place yet (Home Assistant 2026.8 or newer): download tab5_home_assistant.zip and unzip it into Home Assistant's config/ folder, the one holding configuration.yaml; add the line packages: !include_dir_named packages under homeassistant: in configuration.yaml; Developer tools → YAML → Check configuration, then restart Home Assistant. Then pick your sources in the "Tab5 · …" lists (guide, step 1). From 3.7.0, the « Tab5 » integration from HACS can put these files in place and update them in one click (with HACS):
    Open Tab5 in HACS HACS must already be installed: it offers to add the repository, then "Download". The packages: line still has to be added.
  5. Home Assistant découvre la tablette (Paramètres → Appareils et services, intégration ESPHome) : ajoutez-la dans les 30 minutes qui suivent son démarrage, HA lui donne sa clé tout seul. Une tablette que HA connaît déjà reçoit une nouvelle clé sans rien demander.
  6. Home Assistant discovers the tablet (Settings → Devices & services, ESPHome integration): add it within 30 minutes of its boot, HA gives it its key by itself. A tablet HA already knows gets a new key without asking anything.
  7. Rien d'autre à autoriser : la tablette n'envoie que des événements, que le package tab5_evenements.yaml traduit en actions. Seul un firmware 3.1 ou plus ancien demande encore de cocher, dans Appareils et services → ESPHome → Configurer, l'option qui autorise l'appareil à effectuer des actions Home Assistant (la voix, le calendrier et le réveil en ont besoin sur ces versions).
  8. Nothing else to allow: the tablet only sends events, which the tab5_evenements.yaml package turns into actions. Only a 3.1 or older firmware still needs "Allow the device to perform Home Assistant actions" ticked, in Devices & services → ESPHome → Configure (voice, calendar and alarm clock need it on those versions).
  9. Vos appareils : Paramètres → Automatisations et scènes → Blueprints, « Tab5 — emplacements de l'écran · screen slots » (installé par l'archive), puis « Créer une automatisation » : jusqu'à cinq appareils dans « Pièce 1 », le reste est facultatif ; enregistrez. Une seule automatisation par tablette.
    Blueprint absent de la liste (archive pas installée) :
    Importer le blueprint dans Home Assistant Le bouton passe par My Home Assistant, qui demande l'adresse de votre Home Assistant la première fois.
  10. Your devices: Settings → Automations & scenes → Blueprints, "Tab5 — emplacements de l'écran · screen slots" (installed by the archive), then "Create automation": up to five devices in "Room 1", everything else is optional; save. One automation per tablet.
    Blueprint not in the list (archive not installed):
    Import the blueprint into Home Assistant The button goes through My Home Assistant, which asks for your Home Assistant address the first time.
  11. Tableau de bord et réglages (facultatif) : une ligne dans Outils de développement → Modèle écrit un tableau de bord pour la tablette, avec le thème, clair ou sombre, la langue, le réveil et sa santé (guide, étape 7 ; chaque réglage).
  12. Dashboard and settings (optional): one line in Developer tools → Template writes a dashboard for the tablet, with the theme, light or dark, the language, the alarm clock and its health (guide, step 7; every setting).
  13. Mises à jour : l'entité « Firmware » de la tablette les propose dans HA.
  14. Updates: the tablet's "Firmware" entity offers them in HA.

Firmware signé : en OTA, la tablette n'accepte qu'un firmware signé par la clé du projet. Pour compiler le vôtre, voir le dépôt (licence MIT).

Signed firmware: over the air, the tablet only accepts a firmware signed with the project key. To build your own, see the repository (MIT licence).
