  • Une Tab5 reliée à l'ordinateur par un câble USB-C qui transmet les données.
  • A Tab5 connected to the computer with a USB-C cable that carries data.
  • Chrome ou Edge sur ordinateur (Web Serial) ; le bouton le signale sinon.
  • Chrome or Edge on a computer (Web Serial); the button tells you otherwise.
  • Dans la liste des ports, la tablette s'appelle « USB JTAG/serial debug unit ». Si plusieurs ports portent ce nom, débranchez la tablette : celui qui disparaît est le sien.
  • In the port list, the tablet is named "USB JTAG/serial debug unit". If several ports have that name, unplug the tablet: the one that disappears is hers.

  • Home Assistant, with the project's packages and blueprint (guide).

2. Votre révision d'écran2. Your display revision

La puce d'écran est écrite sur l'autocollant au dos, au-dessus du logo Espressif. Une étiquette « ST7123 » peut porter une ST7121 : dans le doute, essayez l'une puis l'autre (détails). The display chip is printed on the sticker on the back, above the Espressif logo. A unit labelled "ST7123" may carry an ST7121: if unsure, try one then the other (details).

4. Installer4. Install

Ce navigateur ne gère pas Web Serial : utilisez Chrome ou Edge sur ordinateur. This browser has no Web Serial: use Chrome or Edge on a computer. La page doit être ouverte en HTTPS. The page must be opened over HTTPS.
  • Première installation (un Tab5 neuf porte la démo de M5Stack) : « Install », puis acceptez d'effacer l'appareil.
  • First install (a new Tab5 carries M5Stack's demo): "Install", then accept to erase the device.
  • Mise à jour d'une tablette déjà installée : « Update », sans effacer : elle garde son Wi-Fi, sa clé de Home Assistant et ses réglages.
  • Updating a tablet already set up: "Update", without erasing: it keeps its Wi-Fi, its Home Assistant key and its settings.
  • Même version déjà installée : pas de bouton « Install ». Pour repartir de zéro, « Erase User Data » (en rouge, en bas) efface tout, Wi-Fi, clé et réglages compris, puis réinstalle.
  • Same version already installed: there is no "Install" button. To start from scratch, "Erase User Data" (in red, at the bottom) erases everything, Wi-Fi, key and settings included, then installs again.
  • « Failed to initialize… holding the BOOT button » : le Tab5 n'a pas de bouton BOOT. Maintenez son bouton reset environ 2 s, jusqu'à ce que la LED verte interne clignote vite : la tablette est en mode téléchargement. Relancez « Connecter et installer » ; à la fin, un appui court sur reset la redémarre.
  • "Failed to initialize… holding the BOOT button": the Tab5 has no BOOT button. Hold its reset button for about 2 s, until the internal green LED blinks fast: the tablet is in download mode. Start "Connect and install" again; at the end, a short press on reset restarts it.
  • Fermer la fenêtre redémarre la tablette une fois : c'est normal.
  • Closing the window restarts the tablet once: that is normal.

5. Ensuite5. Then

  1. Wi-Fi : juste après l'installation, le même bouton propose de le régler (Improv par l'USB). Sinon, connectez un téléphone au réseau ouvert « Tab5 Fallback AP » et choisissez votre réseau.
  2. Wi-Fi: right after installing, the same button offers to set it (Improv over USB). Otherwise, connect a phone to the open network "Tab5 Fallback AP" and pick your network.
  3. Home Assistant découvre la tablette (intégration ESPHome) : ajoutez-la dans les 30 minutes qui suivent son démarrage, HA lui donne sa clé tout seul. Une tablette que HA connaît déjà reçoit une nouvelle clé sans rien demander.
  4. Home Assistant discovers the tablet (ESPHome integration): add it within 30 minutes of its boot, HA gives it its key by itself. A tablet HA already knows gets a new key without asking anything.
  5. Actions HA : dans Appareils et services → ESPHome → Configurer, cochez l'option qui autorise l'appareil à effectuer des actions Home Assistant. Sans elles, la voix, le calendrier et le réveil ne marchent pas.
  6. HA actions: in Devices & services → ESPHome → Configure, tick "Allow the device to perform Home Assistant actions". Without them, voice, calendar and alarm clock do not work.
  7. Vos appareils se choisissent dans le blueprint « Tab5 — emplacements ».
  8. Your devices are picked in the "Tab5 — emplacements" blueprint.
  9. Mises à jour : l'entité « Firmware » de la tablette les propose dans HA.
  10. Updates: the tablet's "Firmware" entity offers them in HA.

Firmware signé : en OTA, la tablette n'accepte qu'un firmware signé par la clé du projet. Pour compiler le vôtre, voir le dépôt (licence MIT).

Signed firmware: over the air, the tablet only accepts a firmware signed with the project key. To build your own, see the repository (MIT licence).
