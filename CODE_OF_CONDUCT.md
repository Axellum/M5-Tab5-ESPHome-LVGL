# Code of Conduct

## English · [Français](#version-française)

This is a small personal project, and everyone is welcome here: in issues, pull requests,
Discussions, and anywhere else the project is discussed. This code of conduct is adapted from
the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

### What we expect

- Be kind and patient. Many people here are hobbyists, and English is not everyone's first
  language — French is just as welcome.
- Assume good faith. Criticise code and ideas, never people.
- Help the next person: share what fixed your problem, even if you found it yourself.
- Respect privacy: never post someone else's personal data, and strip your own Wi-Fi
  passwords, API keys and home details from logs before sharing them.

### What is not accepted

- Harassment, insults, personal or political attacks, trolling.
- Sexualised language or imagery, discrimination of any kind.
- Publishing someone's private information without their explicit permission.
- Anything that would reasonably be considered inappropriate in a friendly, public place.

### Reporting

Report unacceptable behaviour privately to the maintainer (@Axellum) at the e-mail address
shown on the maintainer's GitHub profile. You can also use GitHub's **Report content** menu on
any comment. Reports are read and handled in confidence.

### What happens next

The maintainer may edit, hide or delete comments, lock threads, and temporarily or
permanently ban anyone who does not follow this code — in proportion to what happened,
starting with a private warning whenever that is enough.

## Version Française

C'est un petit projet personnel, et tout le monde y est le bienvenu : dans les issues, les pull
requests, les Discussions, et partout où l'on parle du projet. Ce code de conduite est adapté du
[Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

### Ce qu'on attend

- Soyez bienveillant et patient. Beaucoup de personnes ici sont des amateurs, et l'anglais
  n'est pas la langue de tout le monde — le français est tout aussi bienvenu.
- Supposez la bonne foi. Critiquez le code et les idées, jamais les personnes.
- Aidez la personne suivante : partagez ce qui a réglé votre problème, même si vous l'avez
  trouvé seul.
- Respectez la vie privée : ne publiez jamais les données personnelles de quelqu'un d'autre,
  et retirez vos propres mots de passe Wi-Fi, clés d'API et détails de votre maison des logs
  avant de les partager.

### Ce qui n'est pas accepté

- Le harcèlement, les insultes, les attaques personnelles ou politiques, le trolling.
- Le langage ou les images à caractère sexuel, toute forme de discrimination.
- La publication d'informations privées sur quelqu'un sans son accord explicite.
- Tout ce qui serait raisonnablement jugé déplacé dans un lieu public et convivial.

### Signalement

Signalez un comportement inacceptable en privé au mainteneur (@Axellum), à l'adresse e-mail
indiquée sur son profil GitHub. Vous pouvez aussi utiliser le menu **Report content** de GitHub
sur n'importe quel commentaire. Les signalements sont lus et traités de façon confidentielle.

### Et ensuite

Le mainteneur peut modifier, masquer ou supprimer des commentaires, verrouiller des fils, et
exclure temporairement ou définitivement quiconque ne respecte pas ce code — en proportion de ce
qui s'est passé, en commençant par un avertissement privé chaque fois que cela suffit.
